# 美國觀光旅遊網站(America Tourist website)
webpage : https://zongweichen.github.io/America_Map_Website/
## IDEA
The idea for my website arose from a personal need. As I prepare for a four-month work-and-travel program in the U.S., I wanted to research beyond tourist attractions and find authentic, detailed information about the country. To address this, I created a website where users can search for information by U.S. state, using an interactive map as the main entry point.
